正在连接本机服务…

1. 连接你的网关

密钥保存在此电脑的 data/settings.json，页面不会回显密钥。

本机网关默认使用 8317 端口。

2. 验证一道题

会调用你的 WorkBuddy 模型；命中缓存时直接读取本地答案。

最多 8 张，单张不超过 4 MiB、总计不超过 8 MiB；按顺序对应 [图片1]、[图片2]。使用支持图片输入的模型。

支持文字题，也可上传图片或公式图进行识别。

3. 接入 OCS

  1. 在 OCS 齿轮设置中打开「题库配置」，将下面的完整 JSON 粘贴到配置区，解析器选择「默认」，然后保存。
  2. 脚本管理器请求连接 127.0.0.1 时，允许本机题库连接。
  3. 在 OCS 高级设置中将「搜题最大耗时」设为 120 秒，搜题并发设为 1～2，先用一道练习题核对答案。

服务运行时才能查询。OCS 的「连接成功」只说明本机接口可达；请先完成上面的模型查询。升级后需要重新复制配置，图片与公式图题请开启 OCS 图片题优化。

本地题库

AI 生成的答案可能出错。核对解析后使用；若发现错答，可删除该条缓存，下次查询会重新生成。最多保留最近 1000 条。

数据保存在程序旁的 data 文件夹。网关的模型 API Key 与管理 Key 不同；此处填写用于调用模型的 Key。
